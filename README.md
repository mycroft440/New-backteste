# New-backteste

Novo laboratório de backtest para executar o catálogo completo do `mycroft440/b3-strategy-lab` sobre os dados verificados daquele repositório, com rastreabilidade do commit de origem e execução paralela no GitHub Actions.

A implementação é mantida neste repositório; estratégias, indicadores, dados e regras de carteira permanecem canônicos no `b3-strategy-lab` e são resolvidos por SHA em cada execução.
